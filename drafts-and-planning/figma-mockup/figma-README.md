# OsteoMap UI Design

[Open the project in Figma](https://www.figma.com/design/z0qaS1cjQg7hjLp7gCwK4I/Osteomap?node-id=1-2&p=f&t=zq7ot5i9XcKYjHEk-0)

The Figma file is the current source of truth for the interface design. It was presented to the client at our first meeting to effectively 
communicate our intended design and assumptions for the application. It sparked discussion regarding the user interface and was fundamental
in creating a shared vision of what we expect the user workflow to be.

## Contents

- Mobile interface designs
- Skeleton mapping screen
- Case and specimen forms
- Interactive component designs

Also find in this directory screenshot evidence of the Figma mockup.
